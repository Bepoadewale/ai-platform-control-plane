SECURITY BOUNDARY
What this console cannot do

          

            
Identity is server verified
API requests carry the Keycloak-issued bearer token. The control plane verifies issuer, audience, signature, expiry, tenant, and roles.

            
Policy is enforced live
OPA decides whether an action is allowed, denied, or requires approval. The browser does not decide policy.

            
Plans bind approvals
Protected actions require an independent approval for the exact immutable plan hash. Material changes invalidate the approval.

            
No direct infrastructure authority
Users and agents receive neither Kubernetes credentials, Terraform execution, cloud credentials, nor secret values from this interface.
